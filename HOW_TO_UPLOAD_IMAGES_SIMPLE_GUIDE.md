# 📸 Simple Guide: How to Upload Images (Logo & Icons)

## 🎯 What You'll Upload:
1. **Logo** - Your company logo (for header & email)
2. **11 Garment Icons** - Small icons for each garment type

---

## 📁 STEP 1: Prepare Your Images on Your Computer

### Logo Requirements:
- **File name:** `logo.png` (or `logo.jpg`)
- **Size:** 200px wide x 60px tall (approximately)
- **Format:** PNG (with transparent background) or JPG
- **Where you'll use it:** Header of website and in emails

### Icon Requirements (11 images needed):
- **Format:** PNG (transparent background recommended)
- **Size:** 48x48 pixels (or larger, will be scaled down)
- **File names:** (exactly as shown below - all lowercase)
  1. `shirts.png`
  2. `vneck.png`
  3. `tank.png`
  4. `women-shirts.png`
  5. `polo.png`
  6. `longsleeve.png`
  7. `hoodie.png`
  8. `zip-hoodie.png`
  9. `gaiter.png`
  10. `jersey.png`
  11. `other.png`

**💡 Tip:** Save all 11 icon files in one folder on your computer for easy uploading.

---

## 🚀 STEP 2: Upload to Emergent Platform

### Method 1: Using File Explorer (Recommended for Beginners)

1. **Open your Emergent workspace** (where you're chatting with me)

2. **Look for the file/folder icon** in the left sidebar
   - It might say "Files" or show a folder icon 📁
   - Click on it to open the file explorer

3. **Navigate to the upload folders:**

   **For Logo:**
   - Click: `frontend` → `public` folder
   - Look for or create a folder called `images`
   - Upload your `logo.png` file here
   - Final path should be: `/app/frontend/public/images/logo.png`

   **For Garment Icons:**
   - Click: `frontend` → `public` → `icons` folder
   - Look for or create a folder called `garments`
   - Upload all 11 icon files here
   - Final path should be: `/app/frontend/public/icons/garments/shirts.png` (and so on)

4. **Upload method:**
   - Right-click in the folder
   - Select "Upload" or look for an upload button
   - Select all your files
   - Wait for upload to complete

### Method 2: Tell Me to Create Folders & I'll Guide You

If you can't find the file explorer, just say:
- "Create the folders for me"
- I'll create the folders and give you the exact paths to upload to
